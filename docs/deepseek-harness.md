# ANODHAS Business Hub в DeepSeek Harness

Инструкция для macOS. Схема подключения проверена на DeepSeek Harness 0.2.2-rc.3 с локальным MCP по stdio. Понадобятся установленный Business Hub, его рабочий Python с зависимостями, подготовленная учебная SQLite и каталог карточек Obsidian. Исходники плагина из этого репозитория содержат конфигурацию подключения для Codex. Для Harness используется встроенный MCP-клиент, который обращается к тому же хабу.

## 1. Подключение MCP

В профиле Desktop откройте `~/.dsh/profiles/desktop/cordis.patch.yml`. Для другого профиля выберите его файл `cordis.patch.yml`. Сохраните копию файла и добавьте следующий элемент в конец верхнеуровневого списка. Если подключение с таким ID уже есть, обновите его на месте.

```yaml
- insert:
    - id: mcp-anodhas-business-core
      name: "@deepseek-ai/dsh-mcp-client"
      config:
        serverName: anodhas_business_core
        transport: stdio
        command: "/absolute/path/to/BusinessHub/runtime/hub/bin/python"
        args:
          - "-B"
          - "/absolute/path/to/BusinessHub/core/mcp_hub.py"
          - "--pilot-dir"
          - "/absolute/path/to/BusinessHub/data"
          - "--card-dir"
          - "/absolute/path/to/ObsidianVault/pilot-cards"
        toolCallTimeoutMs: 60000
        failOnStartupError: false
```

Замените все четыре пути на абсолютные пути своей установки. В `--pilot-dir` укажите каталог, содержащий `pilot.sqlite3`. В `--card-dir` укажите каталог, содержащий учебную карточку, которую ожидает ваша сборка хаба. Указывайте Python из окружения хаба, где установлены его зависимости. Проверьте также, что в настройках самого хаба указаны действующие пути к его адаптерам.

После сохранения закройте и снова запустите Harness обычным способом, когда текущие задачи завершатся. Откройте новую сессию с любым уже настроенным провайдером, который поддерживает вызов инструментов.

## 2. Установка двух скиллов

Harness ищет персональные скиллы в `~/.dsh/skills/`. Если у вас уже есть полные версии `business-core-operations` и `supplier-selection`, перенесите каждый каталог целиком, включая его `references/`, если такой каталог есть. Для новой установки создайте два файла с минимальными версиями ниже.

### `~/.dsh/skills/business-core-operations/SKILL.md`

```markdown
---
name: business-core-operations
description: Помогает вести закупки, расчёты, приёмку и сверку оплат через ANODHAS Business Hub.
---

# Работа с закупками

Проверь закупку и её позиции через инструменты сервера anodhas_business_core. Для чтения сохранённого черновика вызови read_discount_draft с ID и версией. Для сравнения предложений подключи скилл supplier-selection. Разделяй расчёт, черновик и подтверждённые факты.

Приёмку и сверку уже совершённой оплаты выполняй по поручению пользователя и по зарегистрированным проверенным документам. Сверяй позицию, количество, остаток и сумму. Перед повтором операции с неизвестным результатом перечитай её состояние. Отражай расхождения между SQLite и карточкой Obsidian.
```

### `~/.dsh/skills/supplier-selection/SKILL.md`

```markdown
---
name: supplier-selection
description: Сравнивает предложения поставщиков по полной стоимости, срокам и условиям поставки.
---

# Сравнение поставщиков

Уточни требуемый объём и условия. Сопоставляй предложения на одинаковом количестве с учётом доставки, налогов и других известных расходов. Помечай отсутствующие данные и допущения.

Для одной позиции используй supplier на сервере anodhas_business_core. Для закупки из нескольких позиций используй compare_supplier_purchase при наличии инструмента. Покажи, у кого ниже полная стоимость, кто привезёт раньше и какие условия ещё нужно уточнить. Сохранение результата и размещение заказа выполняются по отдельному поручению.
```

## 3. Проверка в новой сессии

Возьмите ID и версию уже сохранённого учебного черновика. Отправьте агенту запрос, подставив свой ID и версию.

> Через MCP anodhas_business_core вызови read_discount_draft для учебного черновика с ID <ID> и версией <версия>. Сообщи сумму после расходов. Затем загрузи через инструмент skill скиллы business-core-operations и supplier-selection. Выполни только чтение.

В журнале хода проверьте успешный вызов `read_discount_draft`, сумму из ответа инструмента и два отдельных вызова `skill` с указанными именами. Сумма должна совпасть с контрольным расчётом вашей учебной базы.

На macOS подтверждены запуск сервера из Harness Desktop и сквозное чтение с загрузкой обоих скиллов в новой сессии Harness Headless. Сессии Headless сохраняются на диске. Их отображение в уже открытом Desktop зависит от того, подхватило ли приложение эту историю.
